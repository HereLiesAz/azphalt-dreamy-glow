# Dreamy Glow

A soft ethereal bloom that lifts shadows and blooms highlights — the dreamy, angelic glow that dominates beauty and lifestyle content.

An [azphalt](https://github.com/HereLiesAz/azphalt) extension for
[Guillotine](https://github.com/HereLiesAz/Guillotine).

- **Package id** — `com.hereliesaz.azphalt.dreamy-glow`
- **Version** — 1.0.0
- **Kind** — asset (ISF fragment shader)
- **Tags** — `shader`, `stylize`, `dreamy`, `glow`, `bloom`, `soft-focus`, `one-click`

## Controls

| Parameter | Label | Range | Default |
| --- | --- | --- | --- |
| `amount` | Glow | 0.0 – 1.0 | 0.6 |
| `lift` | Shadow lift | 0.0 – 0.5 | 0.12 |

## Install

Open **Azphalt Store** inside Guillotine, find *Dreamy Glow*, and tap **Install**. The effect is
applied to the selected clip.

To install manually, pack this directory as a `.azp` (a plain ZIP with `manifest.json` at the root)
and side-load it from the store's *Install from file* action.
